
# Indian Cinema Filmography Analysis | Power BI

## 📌 Project Overview

The Filmography Analysis Dashboard is an interactive Power BI project designed to analyze Indian cinema data across different film industries, release years, directors, actors, budgets, box-office collections, profits, and OTT platform shares.

The dashboard provides insights into the financial performance of films, industry-wise comparisons, yearly collection trends, and the contribution of directors and cast members.

The main objective is to transform film industry data into meaningful visual insights that support data-driven analysis of Indian cinema.

## 🎯 Project Objectives

- Compare movie budgets and collections across film industries.
- Analyze box-office collection trends by release year.
- Identify directors associated with higher total movie budgets.
- Explore box-office collections associated with different cast members.
- Track total profit and OTT platform shares.
- Enable interactive analysis using industry, state, hero name, and OTT platform filters.

## 🔍 Key Insights

### 1. Industry-wise Budget and Collection Analysis

- The dashboard compares the total budgets and collections of Bollywood, Kollywood, Tollywood, Mollywood, and Sandalwood.
- Tollywood and Kollywood show substantial budget and collection values in the displayed comparison.
- Mollywood and Sandalwood have comparatively smaller totals in the chart.

**Business insight:** Comparing budgets with collections across industries helps identify differences in investment levels and box-office performance. Profitability should be evaluated separately using consistent financial data.

### 2. Year-wise Box-Office Collection

- The donut chart compares total movie collections across release years.
- The chart shows variations in collections between years, with some years contributing more than others.
- The highest displayed collection segment is approximately 25.11K.

**Business insight:** Year-wise analysis helps identify periods with stronger aggregate box-office collections and provides a starting point for investigating release trends and industry performance.

### 3. Director-wise Budget Analysis

- The line chart compares the sum of movie budgets associated with different directors.
- The displayed totals vary across directors, with the leading value around 3K.
- Several directors have lower aggregate budgets than the highest-budget director.

**Business insight:** Director-wise budget analysis helps compare investment patterns across filmmakers and identify directors associated with larger production budgets.

### 4. Cast-wise Collection Analysis

- The dashboard compares total movie collections associated with different cast members.
- The chart displays noticeable differences in aggregate collection values across the selected cast members.
- Some cast members show higher collection totals than others.

**Business insight:** Cast-wise comparisons can help explore the relationship between film casts and box-office performance. These figures should not be interpreted as proof that a particular actor caused higher collections.

### 5. Profit and OTT Share Analysis

- The dashboard reports a total profit of 81.53K.
- Total OTT shares are displayed as 33.89K.
- These KPIs provide a high-level view of the financial and digital distribution aspects of the filmography dataset.

**Business insight:** Analyzing theatrical performance alongside OTT-related values can help build a broader understanding of movie revenue sources, provided the underlying metrics are consistently defined.

## 💡 Business Recommendations

1. Compare movie budgets and collections to identify potentially profitable films and industries.
2. Analyze yearly collection trends to understand changes in box-office performance.
3. Explore director-wise and cast-wise patterns to identify useful trends for further investigation.
4. Examine OTT-related metrics alongside theatrical collections for a more complete financial analysis.
5. Use the interactive filters to compare industries, states, heroes, and OTT platforms.
